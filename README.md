This project is a Python calculator built using object-oriented programming.

- Created classes, objects, attributes, and methods.
- Used abstraction, inheritance, and polymorphism for different calculations.
- Used the `History` class to manage calculation objects.
- Built a command-line calculator that handles invalid input and recovers without crashing.
- Created tests with `pytest` to verify expected behavior and edge cases.
- Used code coverage and GitHub Actions to automatically test the project.


The project has **37 passing tests** and **100% line and branch coverage**.


The OOP concepts used in this project can transfer to other programming languages, although the syntax and language-specific rules may be different.
